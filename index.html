Quran Madina Html

Quran pages that look like the printed Madina Mushaf, as real text: selectable, searchable and copyable, with no images. Lines are justified the way the print fills them, by stretching the letters themselves. One tag renders a page, a verse range or a few words, with highlighted words and emphasised letters, in the 1441H, 1405H or IndoPak print.

Documentation · Live demo

Getting started

HTML

<script src="https://unpkg.com/quran-madina-html@2"></script>

<quran-madina-html sura="2" aya="255"></quran-madina-html>

React

npm install @tarekeldeeb/quran-madina-react react

import QuranMadinaHtml from "@tarekeldeeb/quran-madina-react";

<QuranMadinaHtml sura={2} aya="255" />

React Native

npm install @tarekeldeeb/quran-madina-react-native react-native-webview

import QuranMadinaNative from "@tarekeldeeb/quran-madina-react-native";

<QuranMadinaNative sura={2} aya="255" />

Flutter

dependencies:
  quran_madina_flutter: ^2.1.3

import 'package:quran_madina_flutter/quran_madina_flutter.dart';

QuranMadinaFlutter(sura: 2, aya: '255')

Vue, Angular, Svelte, Astro

The tag is a standard web component, so it works in any framework: load the script once and use <quran-madina-html> in your templates. Each framework's setup is a few lines; see Vue, Angular, Svelte and Astro.

WordPress

Download the plugin zip, then Plugins → Add New → Upload Plugin. Add the Quran block in the editor, or use the shortcode anywhere:

[quran sura="2" aya="255"]

The library can load from unpkg.com or from a copy on your own site. See WordPress.

Everything else (pages, word selection, highlighting, letters, layouts, styling, offline use, and every option) is in the documentation.
