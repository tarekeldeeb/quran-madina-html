# Frameworks

Thin wrappers around the `<quran-madina-html>` tag. The rendering is the same library in every
case; each wrapper loads it and passes your options through.

- [React](react.md): `@tarekeldeeb/quran-madina-react`, for React on the web and, through
  Capacitor, on iOS and Android.
- [Flutter](flutter.md): `quran_madina_flutter`, for Android, iOS, macOS and the web.

Any other framework can use the tag directly, like any HTML element: see [HTML](../getting-started/html.md).
