# Flutter

```yaml
dependencies:
  quran_madina_flutter: ^2.1.0
```

```dart
import 'package:quran_madina_flutter/quran_madina_flutter.dart';

QuranMadinaFlutter(sura: 2, aya: '255')
```

The widget sizes itself to the text, so it fits in a `ListView` or `Column`. It runs on
Android, iOS and macOS (in the platform's WebView) and on the web (straight in the page), and
can work offline from the app's own assets.

See [Flutter](../frameworks/flutter.md) for every option and the offline setup, and the
[live web example](https://tarekeldeeb.github.io/quran-madina-html/flutter/).
